# personal-website
A personal website built for experience and research

Built with React, Vite, Tailwind CSS, and [shadcn/ui](https://ui.shadcn.com). Frontend only — all content lives in `src/data/content.ts`.

## Development

```sh
npm install
npm run dev      # start the dev server
npm run build    # type-check and build to dist/
```

Add more shadcn components with `npx shadcn@latest add <component>`.

# Sigmoid

- Function
    - $sigmoid=f(x)=\dfrac{1}{(1+e^{-x})}$

![image.png](Sigmoid/image.png)

- $derivative\:of \:sigmoid=f'(x)=\dfrac{e^{-x}}{{(1+e^{-x})}^2}$

![image.png](Sigmoid/image%201.png)

- Traditional activation functions like sigmoid and tanh have **saturation regions** - areas where the function becomes very flat e.g.
    - Sigmoid outputs values are always between 0 and 1, but for very large input number the outputs relatively becomes nearly flat for very large positive or negative inputs
- If your input values are too large or too small (not normalized), neurons easily end up in these saturated flat regions
- When neurons enter these flat regions, the gradients become extremely small (approaching zero). This causes the **vanishing gradient problem** - during backpropagation, these tiny gradients make learning very slow or stop it entirely.
- That's why you needed to carefully normalize inputs to keep them in the "active" range where gradients are reasonable
